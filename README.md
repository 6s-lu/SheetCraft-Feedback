# SheetCraft Feedback & Issue Tracking

Welcome to the official feedback repository for **SheetCraft** - Advanced CSV Viewer Chrome Extension!

## 🎯 Purpose

This repository is dedicated to:
- 🐛 Bug reports
- 💡 Feature requests
- ⚡ Performance issues
- 💬 General feedback and suggestions

## 📝 How to Submit Feedback

### Using the Extension (Recommended)

1. Click the **feedback button** in SheetCraft
2. Fill in the feedback form with:
   - Type (bug, feature, performance, general, praise)
   - Title and description
   - Optional email for follow-up
3. Click **Submit** - your feedback will be copied to clipboard with system diagnostics
4. You'll be redirected to GitHub Issues - just paste and submit!

**Benefits**: Includes automatic system diagnostics, extension version, and current settings.

### Manual Submission

1. Go to [Issues](https://github.com/xampocode/SheetCraft-Feedback/issues/new)
2. Choose a template or create a blank issue
3. Provide as much detail as possible:
   - What happened?
   - What did you expect?
   - Steps to reproduce
   - Extension version (found in settings)
   - Browser version

## 🐛 Bug Report Template

```markdown
## Bug Description
A clear description of what the bug is.

## Steps to Reproduce
1. Go to '...'
2. Click on '...'
3. See error

## Expected Behavior
What you expected to happen.

## Actual Behavior
What actually happened.

## Environment
- Extension Version: v1.1.0
- Browser: Chrome 120.x.x
- OS: macOS / Windows / Linux
- File Size: e.g., 5MB, 1000 rows

## Additional Context
Screenshots, error messages, or other details.
```

## 📊 Issue Labels

We use the following labels to organize issues:

| Label | Description |
|-------|-------------|
| `bug` | Something isn't working |
| `feature` | New feature or enhancement |
| `performance` | Performance optimization needed |
| `documentation` | Documentation improvements |
| `question` | Questions about usage |
| `duplicate` | Duplicate of existing issue |
| `wontfix` | Will not be implemented |
| `priority-high` | High priority issue |
| `priority-low` | Low priority issue |
