# SheetCraft Feedback — archived

**The SheetCraft Chrome extension has been discontinued and is no longer
maintained.** This repository is archived and read-only; no new issues can be
opened here.

## What happened to SheetCraft

The product continues as **THABLES**, as a website and an app. The Chrome
extension is the only part that has been retired — CSV viewing and editing
carry on under the new name.

## Existing issues

Everything opened here is preserved and remains readable. Nothing has been
deleted.
